# 동양 존재론

## 개요

동양 철학은 서양과 다른 독특한 존재론적 관점을 발전시켜왔습니다. 불교, 도가, 유교, 힌두교의 존재론을 살펴봅니다.

## 불교 존재론

### 연기(緣起, Pratītyasamutpāda)

!!! quote "연기의 게송"
    "이것이 있으므로 저것이 있고,
    이것이 생기므로 저것이 생긴다.
    이것이 없으므로 저것이 없고,
    이것이 소멸하므로 저것이 소멸한다."

```
연기의 구조
    ┌─────────────────────┐
    │  조건 A ─→ 결과 A'  │
    │    ↑         │     │
    │    └─── 조건 ───┘   │
    └─────────────────────┘
모든 것은 조건에 의존하여 생성
```

### 공(空, Śūnyatā)

**용수(龍樹, Nāgārjuna)**의 중관학파:

| 개념 | 설명 |
|------|------|
| 공(空) | 자성(自性)의 부재, 실체 없음 |
| 자성(自性) | 독립적, 불변의 본질 |
| 가(假) | 임시적, 가설적 존재 |
| 중도(中道) | 유와 무의 양극단 피함 |

!!! info "공의 의미"
    공은 "아무것도 없다"가 아니라 "실체적 자성이 없다"는 의미입니다.
    존재하되, 고정된 본질 없이 상호의존적으로 존재합니다.

### 오온(五蘊, Pañcakkhandha)

인간 존재의 분석:

```python
class Human:
    """불교의 인간 존재 분석"""

    def __init__(self):
        self.skandhas = {
            "색(色, rūpa)": "물질/신체",
            "수(受, vedanā)": "느낌/감수",
            "상(想, saññā)": "지각/표상",
            "행(行, saṅkhāra)": "의지/형성력",
            "식(識, viññāṇa)": "의식/인식"
        }

    @property
    def self(self):
        """자아는 오온의 결합일 뿐, 실체가 아님"""
        return None  # 무아(無我)
```

### 삼법인(三法印)

불교 존재론의 핵심 특성:

1. **제행무상(諸行無常)**: 모든 형성된 것은 무상하다
2. **제법무아(諸法無我)**: 모든 법에는 자아가 없다
3. **일체개고(一切皆苦)**: 모든 것은 괴로움이다

## 도가 존재론

### 도(道)

!!! quote "노자 『도덕경』 1장"
    "도가도 비상도(道可道 非常道)
    명가명 비상명(名可名 非常名)"

    말할 수 있는 도는 영원한 도가 아니고,
    이름 붙일 수 있는 이름은 영원한 이름이 아니다.

```
도의 특성
├── 무형(無形): 형체가 없음
├── 무명(無名): 이름 붙일 수 없음
├── 선천지(先天地): 천지보다 앞섬
├── 만물지모(萬物之母): 만물의 근원
└── 자연(自然): 스스로 그러함
```

### 유무(有無)의 변증법

```
무(無) ──생성──→ 유(有)
  ↑               │
  └───복귀────────┘

"천하만물은 유에서 생기고,
유는 무에서 생긴다"
(天下萬物生於有, 有生於無)
```

### 기(氣)

동양 존재론의 기본 개념:

| 상태 | 특성 | 결과 |
|------|------|------|
| 응집(凝集) | 기가 모임 | 물질적 형태 |
| 산산(散散) | 기가 흩어짐 | 무형 |

장자(莊子):
!!! quote "장자"
    "삶은 기의 모임이요, 죽음은 기의 흩어짐이다"

## 유교 존재론

### 태극(太極)과 음양

```
        무극(無極)
           │
        태극(太極)
         /     \
      음(陰)   양(陽)
      /  \    /  \
    수   금  목   화
         │
        토
         │
      만물 생성
```

### 이기론(理氣論)

주자학의 존재론:

| 개념 | 성격 | 역할 |
|------|------|------|
| 이(理) | 형이상자, 무형 | 원리, 법칙 |
| 기(氣) | 형이하자, 유형 | 재료, 질료 |

!!! tip "이기의 관계"
    - 이와 기는 분리될 수 없음 (理氣不相離)
    - 이와 기는 섞이지 않음 (理氣不相雜)

```python
class Reality:
    """주자학적 존재론"""

    def __init__(self):
        self.li = Principle()  # 이(理)
        self.qi = Material()   # 기(氣)

    def generate(self):
        """이가 기를 타고 만물 생성"""
        return self.li.ride(self.qi)

    @property
    def unity(self):
        """이기의 합일"""
        return inseparable(self.li, self.qi)
```

## 힌두 존재론

### 브라흐만과 아트만

**베단타 철학**의 핵심:

```
브라흐만 (Brahman)
├── 우주적 실재
├── 무한, 영원, 불변
├── 사트-치트-아난다
│   (존재-의식-환희)
└── 궁극적 실체

아트만 (Ātman)
├── 개인적 자아
├── 진정한 나
└── 브라흐만과 동일
    "Tat tvam asi"
    (너는 그것이다)
```

### 마야(Māyā)

!!! info "마야의 개념"
    - 현상세계는 환영(māyā)
    - 브라흐만만이 진정한 실재
    - 무명(avidyā)이 마야를 야기

### 삼구나(三guṇa)

물질적 자연(Prakṛti)의 세 속성:

| 구나 | 특성 | 표현 |
|------|------|------|
| 사트바(Sattva) | 순수, 조화 | 지혜, 평화 |
| 라자스(Rajas) | 활동, 열정 | 욕망, 행위 |
| 타마스(Tamas) | 어둠, 무기력 | 무지, 나태 |
