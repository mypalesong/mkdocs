# 존재의 범주

## 범주란 무엇인가?

**범주(Category)**는 존재를 분류하는 가장 기본적이고 일반적인 개념들입니다.

!!! info "어원"
    그리스어 **κατηγορία (kategoria)**는 "술어", "진술"을 의미합니다.

## 아리스토텔레스의 10범주

아리스토텔레스는 『범주론』에서 10가지 범주를 제시했습니다:

| 범주 | 그리스어 | 설명 | 예시 |
|------|----------|------|------|
| 실체 | οὐσία | 존재의 기체 | 인간, 말 |
| 양 | ποσόν | 크기, 수 | 2미터, 3개 |
| 질 | ποιόν | 성질 | 흰, 문법적 |
| 관계 | πρός τι | 상대적 규정 | 두 배, 아버지 |
| 장소 | ποῦ | 공간적 위치 | 학당에서 |
| 시간 | ποτέ | 시간적 위치 | 어제 |
| 자세 | κεῖσθαι | 부분들의 배치 | 앉아있음 |
| 소유 | ἔχειν | 가짐 | 신발 신음 |
| 능동 | ποιεῖν | 행위함 | 자름 |
| 수동 | πάσχειν | 당함 | 잘림 |

### 실체 vs 우유(偶有)

```
실체 (Substance)
├── 제1실체: 개별자 (이 사람, 저 말)
└── 제2실체: 보편자 (인간, 동물)

우유/속성 (Accident)
├── 본질적 속성: 종에 필연적 (인간의 이성)
└── 우연적 속성: 개체에 우연적 (소크라테스의 대머리)
```

## 칸트의 범주론

### 오성의 순수 개념

칸트는 『순수이성비판』에서 12범주를 제시했습니다:

```python
KANT_CATEGORIES = {
    "양(Quantity)": [
        "단일성(Unity)",
        "수다성(Plurality)",
        "전체성(Totality)"
    ],
    "질(Quality)": [
        "실재성(Reality)",
        "부정성(Negation)",
        "제한성(Limitation)"
    ],
    "관계(Relation)": [
        "실체와 속성",
        "원인과 결과",
        "상호작용"
    ],
    "양상(Modality)": [
        "가능성/불가능성",
        "현존/비존재",
        "필연성/우연성"
    ]
}
```

!!! note "칸트의 혁신"
    범주는 대상에서 추상된 것이 아니라, **오성이 경험을 구성하기 위해 선험적으로 가지고 있는 개념**입니다.

## 현대적 범주 체계

### 기본 존재론적 범주

현대 분석 형이상학의 분류:

```
존재자
├── 구체적 존재자 (Concrete)
│   ├── 물질적 대상
│   ├── 사건
│   └── 심적 상태
│
└── 추상적 존재자 (Abstract)
    ├── 수학적 대상
    ├── 명제
    └── 속성
```

### 논쟁적 범주들

| 범주 | 실재론 | 반실재론 |
|------|--------|----------|
| 보편자 | 실재한다 | 언어적 구성물 |
| 수 | 플라톤적 대상 | 정신적 구성물 |
| 가능세계 | 실재한다 | 허구적 도구 |
| 추상적 대상 | 존재한다 | 존재하지 않음 |

## 범주적 차이

### 라일의 범주 오류

길버트 라일(Gilbert Ryle)의 개념:

!!! warning "범주 오류의 예"
    "대학교를 보여달라"고 했는데 건물, 도서관, 강의실을 본 후 "그래서 대학교는 어디 있나요?"라고 묻는 것

    → 대학교는 건물과 같은 범주의 존재가 아님

```python
class CategoryMistake(Exception):
    """범주 오류를 나타내는 예외"""
    pass

def check_category(entity, expected_category):
    """범주 확인"""
    if entity.category != expected_category:
        raise CategoryMistake(
            f"{entity}는 {expected_category} 범주가 아닙니다"
        )
```

### 데카르트의 범주 문제

심신이원론의 문제:

```
정신 (사유 실체)     물질 (연장 실체)
    │                    │
    └───── 상호작용? ─────┘
           (범주가 다른데 어떻게?)
```

## 존재론적 다원주의

### 층위 존재론

다양한 존재 층위:

| 층위 | 특성 | 예 |
|------|------|-----|
| 물리적 | 시공간적 | 원자, 분자 |
| 생물학적 | 생명 | 세포, 유기체 |
| 심리적 | 의식 | 감각, 사고 |
| 사회적 | 제도 | 국가, 화폐 |
| 추상적 | 비시공간적 | 수, 논리 |

!!! tip "환원주의 vs 창발주의"
    - **환원주의**: 상위 층위는 하위 층위로 환원됨
    - **창발주의**: 상위 층위는 새로운 속성을 가짐
