    서양 존재론¶

    개요¶

    서양 존재론은 고대 그리스에서 시작되어 현대까지 발전해온 철학적 전통입니다.

    고대 그리스 존재론¶

    전소크라테스 철학자들¶

    존재의 아르케(ἀρχή, 원리)를 탐구:

    철학자 아르케 특징
    탈레스 물 최초의 자연철학자
    아낙시만드로스 아페이론(무한정자) 규정되지 않은 것
    아낙시메네스 공기 농축과 희박
    헤라클레이토스 불/로고스 만물유전
    파르메니데스 존재 불변의 일자

    파르메니데스의 존재론¶

    진리의 길

    "존재는 있고, 비존재는 있지 않다"

    파르메니데스의 존재 특성:

    존재의 특성
├── 불생성: 생겨나지 않음
├── 불멸: 소멸하지 않음
├── 완전: 결핍이 없음
├── 불동: 움직이지 않음
├── 단일: 하나임
└── 연속: 끊어지지 않음

    플라톤의 이원론적 존재론¶

    이데아계 (진정한 실재)
├── 선의 이데아 (최고)
├── 아름다움
├── 정의
├── 평등
└── 기타 형상들...

감각계 (현상)
├── 이데아의 모방
├── 생성소멸
├── 불완전
└── 가변적

    동굴의 비유

    • 동굴 안: 감각 세계 (그림자)
    • 동굴 밖: 이데아 세계 (실재)
    • 태양: 선의 이데아

    아리스토텔레스의 실체 존재론¶

    아리스토텔레스는 플라톤의 초월적 형상을 거부하고, 형상은 개물 안에 내재한다고 주장:

    class Substance:
    """아리스토텔레스의 실체 개념"""

    def __init__(self, matter: 'Hyle', form: 'Morphe'):
        self.matter = matter  # 질료
        self.form = form      # 형상

    @property
    def essence(self):
        """본질 = 형상"""
        return self.form

    def actualize(self, potential: 'Dynamis') -> 'Energeia':
        """가능태에서 현실태로"""
        return potential.realize(self.form)

    4원인론:

    원인 설명 동상 예시
    질료인 재료 청동
    형상인 구조/본질 형태
    작용인 만드는 자 조각가
    목적인 목적 기념/장식

    중세 스콜라 존재론¶

    본질과 존재의 구분¶

    토마스 아퀴나스의 핵심 구분:

    Esse vs Essentia

    • 본질(essentia): 무엇인가 (what it is)
    • 존재(esse): 있음 (that it is)

    피조물에서 본질과 존재는 구분되지만, 신에게서는 본질 = 존재

    보편자 논쟁¶

    보편자는 어디에 있는가?

[실재론] ─── 보편자는 실재한다
    ├── 극단적 실재론 (플라톤)
    │   └── 개물과 독립적으로 존재
    └── 온건한 실재론 (아퀴나스)
        └── 개물 안에 존재

[유명론] ─── 보편자는 이름일 뿐
    ├── 로스켈리누스
    └── 오컴의 윌리엄

    근대 합리론적 존재론¶

    데카르트: 실체 이원론¶

    실체의 종류
│
├── 사유 실체 (res cogitans)
│   ├── 속성: 사유
│   └── 양태: 상상, 감각, 의지...
│
├── 연장 실체 (res extensa)
│   ├── 속성: 연장
│   └── 양태: 모양, 운동, 위치...
│
└── 무한 실체: 신
    └── 두 유한 실체의 원인

    스피노자: 실체 일원론¶

    신 즉 자연

    "신과 자연은 하나다" (Deus sive Natura)

    스피노자의 존재론:

    개념 설명
    실체 유일한 것, 자기 원인
    속성 실체의 본질을 표현 (사유, 연장)
    양태 실체의 변용 (개별 사물들)

    라이프니츠: 단자론¶

    class Monad:
    """라이프니츠의 단자"""

    def __init__(self):
        self.perceptions = []  # 지각들
        self.appetition = None  # 욕구
        self.windowless = True  # 창문 없음

    def mirror(self, universe):
        """우주 전체를 반영"""
        self.perceptions = universe.perspectives

    def pre_established_harmony(self, other: 'Monad'):
        """예정조화"""
        # 직접 상호작용 없이 조화
        return synchronized(self, other)

    버클리의 관념론¶

    버클리

    "존재하는 것은 지각되는 것이다" (Esse est percipi)

    흄의 회의론¶

    • 인상과 관념: 모든 관념은 인상에서 유래
    • 실체 비판: 실체는 관념들의 다발
    • 인과 비판: 습관적 연합일 뿐

    독일 관념론¶

    칸트의 비판적 존재론¶

    현상 (Phenomena)          물자체 (Noumena)
├── 우리가 경험하는 것     ├── 있는 그대로의 것
├── 시공간 형식으로 구성   ├── 알 수 없음
└── 범주로 종합           └── 사유할 수만 있음

    헤겔의 절대적 관념론¶

    변증법적 발전

    • 정(These): 존재
    • 반(Antithese): 무
    • 합(Synthese): 생성
