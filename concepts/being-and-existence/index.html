    존재와 실존¶

    존재(Being)와 실존(Existence)의 구분¶

    기본 개념¶

    개념 정의 특징
    존재(Being) "있음" 일반 추상적, 보편적
    실존(Existence) 구체적으로 "있음" 구체적, 개별적

    철학적 맥락

    이 구분은 특히 실존주의 철학에서 중요해졌습니다. 사르트르는 "실존이 본질에 앞선다"고 주장했습니다.

    존재의 양상¶

    필연적 존재 vs 우연적 존재¶

    필연적 존재 (Necessary Being)
├── 정의: 존재하지 않을 수 없는 것
├── 예: 신 (전통적 형이상학에서)
└── 특징: 그 본질에 존재가 포함됨

우연적 존재 (Contingent Being)
├── 정의: 존재할 수도, 않을 수도 있는 것
├── 예: 인간, 사물, 세계
└── 특징: 원인에 의해 존재하게 됨

    현실적 존재 vs 가능적 존재¶

    아리스토텔레스의 구분:

    도토리와 참나무

    • 가능태(dynamis): 도토리는 가능적으로 참나무
    • 현실태(energeia): 참나무는 현실적으로 참나무
    • 변화 = 가능태에서 현실태로의 이행

    실존의 특성¶

    실존주의적 관점¶

    키르케고르와 사르트르의 실존 개념:

    1. 주체성 (Subjectivity)¶

    "진리는 주체성이다" - 키르케고르

    실존은 객관적으로 관찰되는 것이 아니라 주체적으로 체험됩니다.

    2. 자유와 책임¶

    사르트르

    "인간은 자유롭도록 선고받았다."

    • 실존하는 인간은 자신의 본질을 스스로 만들어감
    • 선택의 자유는 동시에 책임을 수반

    3. 시간성¶

    class Existence:
    """실존의 시간적 구조"""

    def __init__(self):
        self.past = "이미 던져진 상황 (사실성)"
        self.present = "현재의 선택 (결단)"
        self.future = "가능성을 향한 기투"

    def authentic_existence(self):
        """본래적 실존"""
        return "자신의 유한성을 자각하고 책임있게 사는 것"

    존재론적 물음들¶

    "왜 무(無)가 아니라 유(有)가 있는가?"¶

    라이프니츠가 제기한 근본적 물음:

    근본 물음

    이 물음은 존재론의 가장 근본적인 물음으로, 답할 수 없지만 계속 물어야 합니다.

    가능한 답변들:

    입장 답변
    유신론 신이 세계를 창조했기 때문
    자연주의 그냥 우연히 존재함
    범신론 존재 자체가 신이므로
    신비주의 알 수 없는 신비

    존재의 유비 (Analogy of Being)¶

    토마스 아퀴나스의 개념:

    신의 존재 ───────────── 완전한 존재
       │
       │ 유비적 관계
       │
피조물의 존재 ─────────── 파생적 존재

    존재는 일의적(univocal)이지도, 다의적(equivocal)이지도 않고, 유비적(analogical)입니다.

    현대적 논의¶

    존재 양화¶

    콰인(W.V.O. Quine)의 관점:

    존재론적 개입

    "존재한다는 것은 변항의 값이 되는 것이다."

    • ∃x(Fx) : "F인 x가 존재한다"
    • 우리의 이론이 받아들이는 변항의 값 = 우리가 인정하는 존재

    메타존재론¶

    현대 분석철학의 물음:

    1. 존재론적 물음은 어떤 종류의 물음인가?
    2. 존재론적 논쟁은 실질적인가, 언어적인가?
    3. 존재론적 다원주의는 가능한가?
